## 💻 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 글꼴(Pretendard)은 CDN에서 불러오므로 인터넷에 연결되어 있어야 같은 모양으로 보입니다.

## 🌐 배포

GitHub Pages로 배포합니다. 저장소의 Settings → Pages에서 `main` 브랜치의 `/ (root)`를 선택하면, `main`에 push할 때마다 반영됩니다.
